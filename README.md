## 🎨 About the Project

A digital archive and bespoke order platform engineered for a luxury custom sneaker atelier:

- **Momentum-Based Smooth Scrolling:** Integrated Lenis smooth scroll with GSAP trigger sequences for fluid browsing.
- **Editorial Product Showcase:** High-resolution multi-angle photography grids, custom texture deep-dives, and artisan process timelines.
- **Client Inquiry Flow:** Seamless custom order consultation pathways directly connecting collectors with the artist.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 16 (App Router, ISR)
- **UI Engine:** React 19
- **Motion & Scrolling:** GSAP ScrollTrigger + Lenis Smooth Scroll
- **Styling:** Tailwind CSS v4
- **Performance:** Optimized image delivery via Next/Image with WebP format
